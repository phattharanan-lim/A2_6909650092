What I Built

ในงาน Assignment 1 นี้ให้ผมสร้างเว็บไซต์Learning Portfolio แบบหน้าเดียว ให้รู้จักตัวผมมากขึ้น

ส่วนประกอบสำคัญของเว็บไซต์:

  • Header แสดงชื่อ Portfolio และหัวข้อโปรเจกต์
  • Section ข้อมูลเกี่ยวกับตนเอง พร้อมรูปภาพโปรไฟล์
  • Section อธิบายการทำงาน และการสะท้อนความคิด
  • Footer แสดงลิขสิทธิ์และลิงก์ติดต่อ

และในขณะที่เปิดเว็บไซต์จากเครื่องของตัวเองนั้นมี Client เกิดขึ้นแล้ว แต่ยังไม่มี Server เกิดขึ้น

How I Built It

ขั้นตอนการพัฒนางานชิ้นนี้เริ่มจากการวางโครงสร้าง Wireframe บนกระดาษ จากนั้นเขียนโครงสร้าง HTML ด้วยแท็ก Semantic HTML และปิดท้ายด้วยการตกแต่งสไตล์ ตาราง และสีสันด้วย CSS

เครื่องมือและแหล่งข้อมูลที่ใช้ในการเรียนรู้:

  • เครื่องมือเขียนโค้ด: Visual Studio Code
  • แหล่งอ้างอิง HTML/CSS: web.dev และ W3Schools

Reflection

ปัญหาหรือความท้าทายที่พบและการแก้ไข:

ปัญหาเรื่องเวลาที่จำกัดและการเรียนรู้อะไรใหม่ๆ หรือคำสั่งใหม่ๆที่ไม่เคยใช้มาก่อน

สิ่งที่เข้าใจมากขึ้นเกี่ยวกับการพัฒนาเว็บ:

เข้าใจคำสั่งใหม่ๆมากขึ้นและได้เข้าใจวิธีใช้ html กับ css มากขึ้น ได้เพิ่มความคุ้นชินเวลาเขียนโปรแกรม

สิ่งที่อยากปรับปรุงหรือเพิ่มในอนาคต:

อยากหาเวลามาฝึกเพิ่มเพราะการเขียนโปรแกรมด้วยภาษาต่างๆจำเป็นจะต้องมีความคุ้นเคยเป็นอย่างสูง และอย่างปรับปรุงเรื่องที่ไม่สามารถจำคำสั่งบางตัวได้
